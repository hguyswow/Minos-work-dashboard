1

화면 구성 및 접속 방법

Minos Work Dashboard는 현장 운영 환경에 맞춰 3가지 핵심 화면을 제공합니다.

  • 사용자용 화면 (사무실 PC / 스마트폰 조회 및 관리, /): 일반 웹 문서 흐름으로 세로 스크롤되며 작업현황, 장비, 인원, 자재, 특이사항을 한눈에 조회합니다. 헤더에서 [어제 | 어제+오늘 | 오늘] 보기 선택, 날짜 이동, 캘린더, 출력, 관리자 로그인, 파일박스 및 모니터 화면 링크가 제공됩니다. 헤더 타이틀은 중앙에 정돈되며 긴 현장명(최대 40자 이상)도 화면 폭에 맞게 자동 최적화됩니다. 또한 조회 화면의 셀을 더블클릭하면 제자리에서 즉시 인라인 편집할 수 있습니다.
  • 현장 TV 전용 화면 (모니터링 전용 상황판, /tv): 현장 사무실 대형 디스플레이 표출에 최적화된 고정 레이아웃 화면입니다. 세로 스크롤바가 전혀 생기지 않으며, 내용이 긴 구역은 10초마다 자동으로 페이지가 순환 표출됩니다.
    • 우상단 호버 컨트롤 바: ⛶ 전체 화면, ☀/🌙 테마 전환, ✎ 편집 버튼(누르면 관리자 로그인 창 오픈), 상태 라벨(서버 시작 시각 및 오늘 백업 상태 표출).
    • 5분 무조작 자동 복귀: TV의 ✎ 편집 버튼으로 관리자 로그인한 경우, 작업 후 자리를 비워도 5분간 조작이 없으면 자동으로 로그아웃되고 원래의 TV 모니터링 화면으로 안전하게 복귀합니다.
  • 파일박스 (사무실 파일 전달 창구, /files): 도면, 사진, 작업일보 등 사무실 파일을 안전하게 올리고 내려받을 수 있는 현장 파일 공유 창구입니다 (사무실 비밀번호 또는 관리자 인증 필요).
  • 멀티 현장 (여러 현장을 한 서버로, /s/현장코드/): 현장이 둘 이상이면 처음 접속 시 현장 선택 화면이 나타나고, 고른 현장은 브라우저가 기억합니다. 헤더의 현장 전환으로 다른 현장으로 바꿀 수 있습니다. 현장마다 작업 기록·파일박스·관리자 비밀번호·날씨·공고가 분리되며, 모니터는 /s/현장코드/tv 주소로 현장을 지정합니다. 현장 추가·이름 변경·삭제는 선택 화면의 현장 관리에서 총괄 마스터 키로 합니다(새 현장의 관리자 비밀번호는 초기값이므로 입장 후 바꿔 주세요). 현장이 하나뿐이면 이 기능은 보이지 않습니다.
  • 접속 주소 및 네트워크 연결:
    • 서버 PC 본체: http://localhost:3000 (또는 TV 모드: http://localhost:3000/tv)
    • 다른 PC나 스마트폰 접속: 서버 실행 콘솔 창 또는 화면 좌측 하단에 안내되는 IP 주소(http://서버IP:3000)로 접속합니다.
    • 방화벽 확인 안내: 다른 PC나 스마트폰에서 접속이 되지 않는 경우, 서버 PC의 Windows Defender 방화벽에서 포트 3000(TCP 인바운드 허용) 규칙이 등록되어 있는지 확인하십시오.
2

조회 화면, 식수 산정 & 일일 보고서 출력

현장의 작업 현황을 명확하고 체계적으로 표출하며, 종이 인쇄 및 PDF 저장을 지원합니다.

  • 어제 / 오늘 보기 모드: 헤더의 [어제 | 어제+오늘 | 오늘] 버튼으로 원하는 칸을 100% 전체 폭으로 확대하여 집중 조회하거나 전일 대비 당일 작업을 비교 조회할 수 있습니다.
  • 5대 구역 표출 및 테마 컬러: 작업현황(트리 구조 번호 1, ①, ㉮ 계층 유지), 장비 투입(이름, 수량, 규격, 위치), 인원 투입(직종, 인원수, 위치), 자재 반입/사용(종류, 규격, 수량, 단위, 사용처), 특이사항 구역으로 구성되며, 각 섹션 머리글에 고유 테마 컬러 바가 적용되어 시각적으로 직관적입니다.
  • 밑줄 표시 = 직영: 장비, 인원, 자재 중 '직영'으로 지정된 항목은 텍스트 밑줄(직영 항목)로 표출되어 도급(외주) 업체 작업과 즉시 구분됩니다.
  • 장비 수량 표출: 장비 투입 구역의 열이 "수량"으로 표출되며, 수량이 미입력된 항목은 흐린 텍스트로 안내됩니다.
  • 식수 인원 산정 규칙 & 세부 내역 조회 (중요):
    식수 인원 = 직원(관리자/기사) + 직영 인원 + 직영 장비 수량(대수)
    ※ 도급(외주) 업체는 자체 식사를 원칙으로 하므로, 직종이 '직원'이거나 토글이 '직영'으로 켜진 인원, 그리고 '직영'으로 지정된 건설장비의 운전기사(대수만큼, 수량 미기재 시 1명)만 식수 인원에 자동 합산됩니다.
    인원투입 머리글에 표출된 식수 배지(식수 N명)를 클릭하면 "식수 인원 상세" 모달 창이 열려 산출 근거를 투명하게 확인할 수 있습니다. 모달에는 직종별 인원수(직원 및 직영)와 직영 건설장비 기사 수량(대수, 미기재 시 1명)이 행별로 상세히 나열되며, 마지막 행에 식수 합계 N명이 표출됩니다.
  • 화면에서 바로 편집 (더블클릭 제자리 편집): 조회 화면(/)에서 각 구역의 셀을 더블클릭하면 관리자 비밀번호를 확인한 후 해당 칸만 즉시 인라인으로 편집하여 저장할 수 있습니다. 편집 가능한 칸은 작업현황(내용), 장비(장비명, 수량, 규격, 위치), 인원(직종, 인원수, 위치), 자재(종류, 규격, 수량, 단위, 사용처), 특이사항(내용)입니다.
  • 일일 보고서 출력 및 PDF 저장 (인쇄 최적화): 상단 헤더의 출력 버튼(또는 키보드 Ctrl + P)을 누르면 불필요한 컨트롤이 모두 숨겨진 A4 인쇄 서식으로 전환됩니다.
    • 외곽선 및 구분선: 전체 외곽 실선(1px) 및 어제/오늘 사이 가운데 세로 구분선(1px)이 선명하게 복원되며, 내부 2열/3열 사이에도 세로선이 표시됩니다.
    • 좌우 높이 일치: 어제와 오늘의 내용량 차이가 커도 양쪽 칸 높이가 자동으로 맞춰집니다.
    • 글자 잘림 방지 (자동 줄바꿈): 긴 작업명이나 위치명도 칸 오른쪽에서 잘리지 않고 다음 줄로 자동 줄바꿈되어 모든 내용이 온전히 출력됩니다.
    • 관리자 화면에서도 보고서 양식 인쇄: 관리자 모드에서 인쇄하더라도 입력창 테두리와 편집 버튼이 모두 사라지고 조회 모드와 동일한 최종 보고서 텍스트 양식으로 인쇄됩니다.
    • ※ 인쇄 팁: 모니터 화면(/tv)에서 브라우저 인쇄를 누르면 화면에 표출 중인 현재 페이지만 나오므로, 전체 일일 보고서 인쇄는 반드시 일반 화면(/)의 [출력] 버튼을 이용하십시오.
  • 지난 날짜 열람 (달력 이력 조회): 상단 헤더의 지난 날짜 버튼을 누르면 7열 달력이 열리며, 과거 기록이 존재하는 날짜에는 파란색 점(●)이 표시되어 클릭 시 과거 5대 구역의 기록을 읽기 전용으로 안전하게 열람할 수 있습니다.
3

관리자 입력, 복사 & 편의 기능

작업 데이터를 입력하거나 수정할 때 필요한 관리자 기능입니다.

  • 관리자 로그인: 화면 우측 상단의 옅은 관리자 글씨(또는 TV 화면의 ✎ 편집 버튼)를 누르고 관리자 비밀번호(최초 기본값: 0000)를 입력합니다. 초기 비밀번호 상태(기본값/마스터 초기화 0000)로 로그인하면 화면 상단에 안내 배너와 비밀번호 변경 버튼이 표시되며, 비밀번호를 바꿀 때까지 계속 보입니다(설정 창이 저절로 열리지는 않습니다).
  • 어제 내용 → 오늘 복사 (항목별 선택 복사): 상단의 어제 내용 → 오늘 복사 버튼을 누르면 모달 창이 열려 작업현황, 장비, 인원, 자재, 특이사항 중 원하는 항목만 체크박스로 골라 복사할 수 있습니다. 오늘 칸에 이미 작성된 내용이 있을 경우 덮어쓰기 전 확인 창이 제공됩니다.
  • 장비 수량 입력: 장비 등록 시 대수를 "수량" 칸에 숫자로 입력합니다. 수량이 비어있으면 붉은 테두리로 안내되며, 직영 장비의 수량만큼 식수 인원에 실시간으로 자동 합산됩니다.
  • 직영 ON/OFF 토글: 장비, 인원, 자재의 행마다 위치한 [직영] 버튼을 원클릭으로 켜고 끌 수 있으며, 켜진 항목은 밑줄 처리 및 식수 인원 집계에 실시간 반영됩니다.
  • 항목 추가/삭제 및 빠른 입력: 표의 마지막 입력칸에서 Enter 키를 누르면 다음 행이 자동 생성됩니다. 자재 입력 시 12종 표준 단위 자동완성이 지원되며, 최근 180일간의 입력 이력이 드롭다운 추천으로 표시됩니다.
  • 순서 변경 (▲/▼ 버튼 및 드래그): 표 내부 항목 행을 위/아래 이동 버튼이나 마우스 드래그를 통해 원하는 순서로 손쉽게 재배치할 수 있습니다.
  • 구역 높이 조절 및 실시간 저장: 인접한 두 구역 사이의 경계선(리사이즈 핸들)을 드래그하여 높이 비율을 조절할 수 있습니다 (더블클릭 시 균등 복원). 조절 후 하단 바의 [저장]을 클릭하면 서버에 영구 반영되어 연결된 모든 TV와 PC 화면에 동일하게 적용됩니다.
  • 구역별 열 배치 (1열/2열/3열/자동): 상단 설정 창에서 각 구역의 열 수를 1열, 2열, 3열, 또는 '자동(0)'으로 지정할 수 있습니다. '자동'으로 설정하면 구역 높이에 따라 내부 1단~3단으로 가변 분기되어 빈 공간을 최소화합니다.
4

월별 계획 & TV 공고 알림

현장의 중장기 공정 일정과 긴급 안전 알림을 효과적으로 운영합니다.

  • 월별 계획 관리 (달력 메모): 관리자 로그인 후 상단 헤더의 월별계획 버튼을 누르면 7열 달력이 열립니다. 날짜를 클릭하여 주요 공정 일정을 추가/수정/삭제할 수 있습니다.
    • 일반 일정만 있는 날: 날짜 아래 회색 점(●) 표출
    • 공고 일정이 포함된 날: 날짜 아래 하늘색 강조 점(●) 표출
  • TV 예약 공고 (지정 시각 자동 표출): 일정 등록 시 "공고로 표시"를 체크하고 시작 시각(HH:MM)과 지속 시간(분)을 지정하면, 해당 시각에 현장 TV(/tv) 화면 위로 뒷배경을 가리지 않는 떠다니는(floating) 알림 카드가 자동 표출되며 시간이 지나면 자동 소멸합니다.
  • TV 즉시 공고 (오버레이): 월별계획 창 하단의 🚨 TV 즉시 공고 (오버레이) 영역에서 긴급 공지 내용을 적고 [지금 표시]를 누르면 연결된 모든 TV 전광판에 즉시 알림이 표출됩니다. 표출 중 관리자가 [공고 해제]를 누르면 즉시 사라집니다.
  • TV 화면 무결성 유지: 공고 알림은 반투명 오버레이로 띄워져 뒷배경의 작업 현황을 가리지 않으며, TV 화면의 고정 높이(scrollHeight == innerHeight) 및 10초 구역 순환 타이머에 일체 간섭하지 않습니다.
5

환경설정 & 날씨

상단 우측의 설정 버튼(관리자 전용)에서 현장 환경을 맞춤 설정할 수 있습니다.

  1. 현장명 설정: 상단 타이틀과 TV 화면에 표출되는 현장 명칭(예: "OO지구 신축공사 현장")을 입력합니다. 헤더 중앙에 배치되며 긴 현장명(최대 40자 이상)도 시계나 버튼과 겹치지 않게 자동 적응합니다.
  2. 날씨 위치 설정 (Open-Meteo): 기상 API 키 없이 30분 간격으로 당일 6~20시(2시간 간격 8칸) 날씨를 자동 수신합니다. 한글 주요 20개 도시 검색 또는 영문 도시명/위도·경도를 직접 입력할 수 있으며, 설정된 좌표는 재시작 후에도 안전하게 유지됩니다.
  3. 날씨 칸 컬러화 & 기온 색상: 맑음, 구름/흐림, 비, 눈, 안개, 천둥번개 등 날씨 상태에 맞춰 파스텔 톤 배경이 적용되며, 5℃ 이하 저온은 파란색, 28℃ 이상 고온은 빨간색으로 기온이 강조 표출됩니다.
  4. 강풍 / 강우 안전 경고 기준: 풍속(m/s) 및 강수량(mm/h) 기준을 설정합니다. 기준 초과 시 해당 시간대 슬롯이 붉은색으로 강조되며 경고 배지가 표출됩니다 (0 입력 시 해당 경고 끔).
  5. 오늘 수동 날씨: 인터넷이 연결되지 않은 현장이거나 기상 수신이 3시간 이상 지연될 경우, 관리자가 직접 입력한 수동 8칸 날씨(날씨 아이콘, 기온, 풍속)로 자동 전환(fallback)되어 화면이 중단되지 않습니다.
  6. 레이아웃 설정: 5개 구역의 표출 순서 변경(▲/▼), 전체 폭 확장 여부, 구역 내부 다단(자동 0단, 1단, 2단, 3단)을 설정합니다.
  7. 비밀번호 관리: 관리자 및 사무실 비밀번호 변경 및 분실 방지 힌트를 설정합니다.
6

비밀번호 관리 & 보안

현장 권한 분리와 안전한 보안 관리를 위해 비밀번호 체계를 제공합니다.

  • 관리자 비밀번호 (password): 일일 작업 일보 입력, 공지사항 등록, 환경설정, 파일박스 파일 삭제에 사용되는 현장 최고 권한 비밀번호입니다 (최초 기본값: 0000, config.json에 password 설정 시 해당 값 우선, 마스터 복구 시 0000으로 초기화).
  • 사무실 비밀번호 (officePassword): 파일박스(/files)에서 파일을 올리고 조회/다운로드할 수 있는 사무실 공용 비밀번호입니다 (기본값: 0000).
  • 화면에서 비밀번호 변경: 관리자 로그인 후 설정 모달의 비밀번호 관리 메뉴에서 현재 비밀번호를 확인하고 새 비밀번호(4~32자, 공백 불가)와 힌트(최대 60자)를 설정할 수 있습니다. 변경 즉시 config.json에 scrypt 안전 해시로 암호화 저장됩니다.
  • 비밀번호 힌트 확인: 로그인 창 하단의 힌트 보기 버튼을 누르면 설정해 둔 힌트가 즉시 표출됩니다.
  • 비밀번호 분실 시 마스터 복구 (중요): 관리자 로그인 창에서 비밀번호를 잊으셨나요? 버튼을 클릭하고 마스터 비밀번호를 입력하면 관리자 비밀번호가 즉시 0000으로 초기화됩니다.
마스터 복구 키 확인 방법
마스터 복구 키는 서버 PC의 config.json 파일 내 "masterPassword" 항목입니다. 첫 번째 현장과 총괄 마스터 키(현장 추가·이름 변경·삭제용)는 처음에는 0000으로 저장되며, 서버 시작 로그에 초기값 경고가 표시됩니다. 추가한 현장의 복구 키는 해당 현장 폴더(sites/현장코드/config.json)에 16자리 무작위 값으로 자동 생성됩니다. 이미 키가 저장된 config.json은 업데이트해도 바뀌지 않습니다. 키를 잊었거나 초기화하려면 서버 PC에서 config.json(설치본: %LOCALAPPDATA%WorkDashboardconfig.json)을 메모장으로 열어 "masterPassword": "0000"으로 고쳐 저장하면 됩니다(총괄 마스터 키는 재시작 없이 즉시 적용, 줄을 지우고 재시작해도 0000으로 다시 만들어집니다). 추가한 현장은 sites/현장코드/config.json에서 같은 방식으로 고칩니다. 실제 운영 전에는 config.json에서 0000 대신 다른 값으로 바꿔 두십시오.
7

데이터 관리, 백업 & 설치 운영

현장 서버 PC에 데이터를 로컬 보관하며 2중 안전 저장 장치와 무중단 운영 환경을 갖추고 있습니다.

  • 데이터 파일 구조:
    • data.json: 메인 일일 작업 데이터 (최근 180일 캐시).
    • work.db: SQLite 내장 DB (WAL 모드, 과거 모든 일별 이력 무제한 누적 보존).
    • files/: 파일박스에 업로드된 현장 파일 보관 폴더 (최대 5GB 관리).
    • config.json: 포트 번호, 시스템 설정 및 비밀번호 해시.
  • 일일 자동 백업 (backup/): 서버 시작 시 및 그날 첫 저장 시 backup/data-YYYY-MM-DD.json 및 backup/work-YYYY-MM-DD.db 스냅샷이 자동 생성되며 최근 30개 분량이 안전하게 유지됩니다.
  • 백업 복원 절차:
    1. 실행 중인 서버 콘솔 창을 닫아 서버를 완전히 종료합니다.
    2. backup/ 폴더에서 복원할 날짜의 백업 파일을 복사합니다.
    3. 프로젝트 루트(또는 데이터 폴더)에 붙여넣고 이름을 data.json (DB의 경우 work.db)으로 변경합니다.
    4. 서버를 다시 시작합니다.
  • 설치 프로그램 및 트레이 런처:
    • 윈도우 전용 설치본(WorkDashboard-Setup-1.2.1.exe)으로 설치 시, PC 부팅 시 백그라운드로 자동 실행되는 시스템 트레이 런처가 함께 설치됩니다.
    • 설치본의 기본 데이터 폴더는 %LOCALAPPDATA%\WorkDashboard에 안전하게 격리 보관되며, 필요 시 환경변수 WD_DATA_DIR을 통해 원하는 드라이브나 폴더로 지정할 수 있습니다.
  • 자동 재시작 및 시작프로그램 스크립트:
    • run_forever.bat: 서버 프로세스가 예기치 않게 종료되면 5초 후 자동으로 다시 시작합니다.
    • install_autostart.bat / uninstall_autostart.bat: Windows 작업 스케줄러를 통해 사용자 로그온 시 백그라운드 자동 실행을 손쉽게 등록 및 해제할 수 있습니다.

TV 현장 운영 팁 & FAQ

현장 사무실 및 상황실 모니터에서 안정적으로 전광판을 24시간 가동하기 위한 노하우입니다.

  1. 전체 화면 전환 (F11): 브라우저에서 키보드 F11 키를 누르거나 마우스 호버 시 우측 상단에 나타나는 ⛶ 전체 화면 버튼을 누르면 주소창과 탭이 숨겨진 풀스크린 상황판으로 전환됩니다 (원래대로는 Esc 또는 F11).
  2. 부팅 시 자동 실행 설정:
    Win + R → shell:startup(시작프로그램 폴더)에 바로가기를 넣고 대상 경로 끝에 --kiosk http://localhost:3000/tv를 추가하면 PC 부팅 즉시 전체화면으로 자동 시작됩니다. (또는 install_autostart.bat 실행)
  3. 디스플레이 번인 방지 (다크 모드 권장): TV 화면을 24시간 켜둘 경우 우측 상단 호버 시 나타나는 ☀/🌙 테마 버튼으로 다크 모드를 적용하면 패널 번인(잔상) 예방과 전력 절감에 효과적입니다.
  4. 서버 재시작 시 자동 복구: 서버 PC가 재시작되어 일시적으로 연결이 끊기더라도 브라우저가 SSE(Server-Sent Events)를 통해 몇 초 내로 자동 재연결하여 화면을 복구합니다.
  5. 자주 묻는 질문 (FAQ):
    증상 및 질문 원인 및 조치 방법
    다른 PC/TV에서 접속 불가 ① 동일 공유기(LAN/Wi-Fi) 연결 확인 ② 서버 PC의 Windows Defender 방화벽 포트 3000(인바운드 허용) 규칙 등록 확인 ③ 서버 좌하단 표시 IP 변경 여부 확인
    TV 화면에서 데이터를 수정하고 싶을 때 마우스를 화면 우측 상단으로 이동하면 나타나는 ✎ 편집 버튼을 클릭하십시오. 관리자 로그인 창이 열리며, 편집 완료 후 로그아웃하거나 5분간 조작이 없으면 자동으로 모니터링 화면으로 복귀합니다.
    관리자 비밀번호를 잊어버렸을 때 로그인 창에서 힌트 보기를 누르거나, 비밀번호를 잊으셨나요?를 클릭한 뒤 서버 PC의 config.json 파일에 등록된 16자리 masterPassword를 입력하여 0000으로 초기화합니다.
    일일 보고서 출력 시 글자 잘림이나 서식 상단 헤더의 출력 버튼(Ctrl+P)을 누르면 A4 서식에 맞춰 외곽 테두리, 구분선, 긴 글자 자동 줄바꿈이 일괄 적용되어 깔끔한 인쇄본이 출력됩니다. (TV 화면 대신 일반 화면 /에서 출력 권장)
    파일박스 삭제 버튼이 안 보임 파일 삭제는 관리자 전용 권한입니다. 대시보드(/)에서 관리자로 로그인한 후 파일박스로 이동하십시오.
    화면 구역 순환/스크롤이 멈춤 관리자 편집 중이거나 모달 창이 열려 있으면 편집 편의를 위해 순환이 일시 정지됩니다. 편집 후 창을 닫으면 정상 재개됩니다.
